# 🚀 Next.js Auth & Profile App

თანამედროვე ვებ-აპლიკაცია, აგებული **Next.js**-ზე, რომელიც უზრუნველყოფს მომხმარებლის ავტორიზაციას (Sign In / Sign Up) და პირად პროფილზე გადასვლის ფუნქციონალს.

---

## 📌 ფუნქციონალი (Features)

- 🔐 **Sign Up (რეგისტრაცია):** ახალი მომხმარებლის ანგარიშის შექმნა.
- 🔑 **Sign In (ავტორიზაცია):** სისტემაში შესვლა უსაფრთხოების ნორმების დაცვით.
- 👤 **Profile Page (პროფილი):** მომხმარებლის პირადი გვერდი და მონაცემების ჩვენება.
- 🔄 **Protected Routes:** დაცული მარშრუტები — პროფილის გვერდზე წვდომა მხოლოდ ავტორიზებული მომხმარებლებისთვის.
- 🎨 **Responsive UI:** სრულად ადაპტირებული დიზაინი ყველა ტიპის ეკრანისთვის.

---

## 🛠 ტექნოლოგიები (Tech Stack)

- **Framework:** [Next.js](https://nextjs.org/) (App Router / Pages Router)
- **Language:** JavaScript / TypeScript
- **Styling:** Tailwind CSS / CSS Modules
- **Authentication:** NextAuth.js / Custom Auth
- **Database / Backend:** Node.js, Express / MongoDB / Firebase *(სურვილისამებრ მიუთითე)*
